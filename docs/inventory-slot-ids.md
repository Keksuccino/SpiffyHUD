# Inventory Slot IDs

Many of Spiffy's inventory-related features need you to use slot IDs. These IDs are defined by the game to identify slots in the player's inventory.

## Hotbar

- **Slot IDs:** 0 to 8
- The first hotbar slot is 0.

## Main Inventory

- **Slot IDs:** 9 to 35
- The top-left main inventory slot is 9.

## Armor Slots

- **Slot IDs:** 36 to 39
- 36 (boots), 37 (leggings), 38 (chestplate), 39 (helmet)

## Offhand Slot

- **Slot ID:** 40
