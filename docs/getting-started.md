## Getting started

Since Spiffy is an addon for FancyMenu, there's not much to say in here, because everything works exactly like in FancyMenu!<br>
To learn how to use SpiffyHUD, please check out [FancyMenu's documentation](https://docs.fancymenu.net)!

## How to Access Spiffy's Customization Screen

To customize the HUD, just click on the big button in the top-left corner, right below FancyMenu's menu bar, in the **Pause screen**! The button's icon looks like a chestplate with a mouse cursor.

<img width="766" alt="Screenshot_1" src="https://github.com/user-attachments/assets/a7957858-a406-4059-8710-257a656bc71c" />

<p>

You will then see an empty screen with just the world — and the HUD — visible, which is not a bug. Spiffy is a HUD customization mod, that’s why you only see the HUD. The only other thing you should see is FancyMenu's customization menu bar at the top. Spiffy makes FancyMenu think the HUD is a normal GUI screen, so you can customize the HUD now like a normal screen, which means you click on **menu bar -> Customization** and create a new layout **for the current screen**.
