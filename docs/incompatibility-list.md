# List of Incompatible Mods

The following mods are known as incompatible with SpiffyHUD.

If you’ve found an incompatible mod which isn’t already in the list, please report it to me by [opening an issue ticket](https://github.com/Keksuccino/FancyHud/issues).<br>
Thank you very much!

## Incompatible Mods:

- [Gnetum](https://www.curseforge.com/minecraft/mc-mods/gnetum) (Breaks HUD customization -- Vanilla elements can't be removed)
